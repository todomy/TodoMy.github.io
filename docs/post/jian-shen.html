健身

Tip

每个人活着都需要身体，身体的好坏能够直接影响到你的生活质量，所以我们应该在我们的身体上投入更多的精力跟资源。

曾经的自己

本人从小好爱运动，喜欢打篮球，踢足球，日常还喜欢做俯卧撑，学生时代通过锻炼和体育活动，排解学习的无聊，那时候年轻，身体代谢，柔韧性都比较好，也曾周末去网吧包夜两天两夜通宵，有过这类惊人战绩，也有大夏天中午同学一起打篮球打到嘴唇都干脱皮，也曾冬天下河洗冷水澡，嘴巴都冻紫掉，年少春风得意马蹄疾，身体没有任何不适，哪怕打篮球两只脚崴了，肿胀的跟大馒头一样，也只是几周就会恢复，那时的自己以为身体永远都这么让人如臂挥使。

牛马十年

毕业后工作了几年，久坐办公室后，基础代谢下来了，体重上来了，肌肉消失了，过年开车回家，晚上出发，到了凌晨还堵在路上，睡了一会，醒来后背疼痛，后背筋膜炎找上了门，那一块肌肉好像缩在了一起，急性期吃不好睡不好。后续过了通过锻炼慢慢缓解，随着久坐，身体结构也发生了改变，没有一个人可以在久坐的环境下，还能保持良好的姿态，形体。日积月累，身体在慢慢的变差，走路也开始感觉左右不平衡，然后就是腰痛也找上了门，关节也有了损伤，腰肌劳损，各类不适找上门，让你痛苦不堪，内耗焦虑，抢走了你的能量跟精力，以上这些变化是工作十年就会陆续出现，这些都是当牛马的危害，日积月累中你被腐蚀殆尽。

改变

不想坐以待毙，要去做一些什么，去阻止它，那怎么样才能阻止呢？

  1. 财富自由，又或者收支平衡，不用做牛马
  2. 做自由职业，独立自主的安排时间跟自身工作状态姿态等
  3. 日常持续锻炼打磨这具身体

我想我可能1跟2 都没有办法立马完成，所以选择了3，开始尝试各类运动

运动

由于身体已经肌肉含量减少，实际上不适合去做一些强度训练

游泳

我最先想到的是这个运动，也进行了尝试，本身自己就有野外大河游泳的经历，年少生活在农村，夏天经常在河里游泳，常规的踩水，狗刨，蛙泳这类都是没问题的。
经过实践后发现游泳有以下问题：

  1. 需要专门泳池场地，水要勤换，不勤换的会得中耳炎跟皮肤病
  2. 脱换洗麻烦，每天带装备带衣服
  3. 需要门票费，要钱
  4. 游泳姿势不对更伤人，有些人身体更严重了。
  5. 人太多时候会有肢体冲突，曾被人踢对方还嚣张差点打起来

所以我觉得游泳这个运动虽然说优点很多，但是这些缺点对于小白来说实际上不友好

健身房

我也去健身房去练器械，各种器械也跟着视频进行了学习，学习发力，学习姿势，学习固定，确实有成效，一两个月下来，肌肉维度上来了，但是也有其他问题。

  1. 大重量损伤关节，不管你如何姿势正确发力如何好，你根本不知道自己该上多大的重量，重量大了，整个运动幅度实际上你已经失去了你的控制，就会对关节进行冲击，甚至有时候也会造成事故
  2. 肌肉比关节更快适应重量，关节在这个过程中被磨损损伤
  3. 小白需要经过一些专业学习，才能够掌握正确的发力，器械使用
  4. 需要花钱
  5. 需要专业的场地
  6. 器械卫生堪忧，到处是汗液，有时候锻炼反而增加交叉感染风险
  7. 器械需要等待，有些人占着刷手机

这也就导致了很多人无法在健身房里坚持下去，现代健身房本质上是商业化的结果，你需要花钱去办卡，去购买器械，去买蛋白粉肌酸，花钱私教，你会发现整套都是一个健身产业的商业循环。

而实际上的健身本应该免费，人人唾手可得，以下我将讲述如何不花钱进行锻炼

自重训练

所有的大重量都会伤关节，那我们应该以什么样的重量为标准呢？
人类的基因跟黑猩猩相似度最近，是分离最近的物种，可以想一下人类的祖先应该也能够在树上生活，也能够进行攀爬，抓握树枝进行划动穿越树林

人类锻炼身体应该是为了更好的灵活控制自身身体，而不是为了锻炼出更大的肌肉，去推动更大的物体。

囚徒健身是一个很好的自重训练，大家可以将六艺的前三式重复锻炼，慢慢锻炼，循序锻炼，对照视频，学习，然后将其打磨完美，身体也就拥有了一定的基础力量跟韧性

日常锻炼

我们每个人每天除了上班还有其他的角色，例如是个父亲，母亲，家庭事务，所以很多时候并没有更多时间跟机会进行锻炼。
因此要利用日常生活中的碎片化时间，进行一些有氧锻炼

  1. 坐电梯改成爬楼，爬楼时双手放在臀部，感受发力
  2. 日常行走微微收紧腹部核心
  3. 久坐忙的时候勾脚抖腿
  4. 站立时候进行踮脚
  5. 上班上厕所路上伸展身体，抬抬腿
  6. 上班多喝水多去倒水就能起来走走
  7. 下班后小区公园散步或快走二十分钟

日常碎片化的有氧运动尤其重要，身体在日积月累中腐蚀殆尽，那我们就用碎片化的运动去维护，减缓。

训练节奏

训练强度跟节奏每个人恢复能力不同，身体情况不同，以下是我针对小白的个人主观建议：

  1. 自重训练，六艺十式小白初始阶段一周两到三次即可，每次中间间隔两天，每次选择最简单的那一个即可，然后练至完美再依次下一个，逐渐进阶，根据身体情况进行调整。
  2. 速度，采取匀速，人类更擅长匀速而非爆发性，爆发性的运动对于肌肉弱的人来说就会损坏关节，另外所有的运动都要采取匀速控制，这样子能够保证整个运动幅度都在你的力控内，否则就是有害的，也是为什么健身器械很多人关节损伤原因，因为他们根本无法控制整个运动幅度，收跟放都要去控制。另外整个过程也在锻炼你的神经，光有肌肉实际上并不行，还要有强大的神经，这才是关键
  3. 锻炼是要锻炼整个身体而非机械控制锻炼某一块肌肉；身体是一个整体，自重训练就是在锻炼整个身体的协调性，而非将某快肌肉练大，这样子只会导致肌力不平衡，身体失调。
  4. 量力而行，锻炼是一方面了，不受伤，通过身体自重去控制身体强度，不行就停，完美的练习两组，远比精疲力竭更好，精疲力竭只会导致你受伤，推迟你的运动
  5. 记住力量的秘诀不在于训练时间的长短，而在于你有没有有效训练。
  6. 好好休息，休息好睡好，才能让肌肉神经增长恢复，锻炼只是其中一部分，重要的是休息恢复
  7. 慢就是好，慢就是快。

饮食

这里我推荐地中海改饮食，比较简单，自己吃的话也容易一些，日常饮食最好把下列食物带上：

  1. 鸡蛋，这是我认为最好的蛋白质微量元素廉价获取方式，鸡蛋包含一个生命体发育成为小鸡所有的营养元素，关键他便宜，吃鸡蛋要蛋黄，所谓的胆固醇高都是扯淡的，如非医嘱疾病，推荐每天都要吃鸡蛋
  2. 牛奶
  3. 坚果
  4. 碳水，大部分用粗粮杂粮替代
  5. 蔬菜

维度 中式精简建议（参考）
核心口诀 杂粮垫底、多菜少肉、鱼虾当家、好油烹煮、天然调味
🍚 主食怎么吃？ 杂粮饭（大米:糙米/燕麦/小米=1:1）、蒸红薯/玉米。
❗ 戒掉每顿纯白米饭，早餐可用杂粮粥或全麦馒头代替。
🥬 蔬菜吃多少？ 每餐至少半斤（约1饭碗），深绿色叶子菜（菠菜、油菜、西兰花）占一半。
冰箱常备菌菇类（香菇、木耳）增加口感。
🍳 用什么油？ 日常炒菜用山茶油或高油酸菜籽油（耐热且富含单不饱和脂肪酸）。
凉拌菜可用芝麻油或普通橄榄油（无需特级初榨）。
🐟 肉类怎么选？ 每周吃鱼/虾至少3次（推荐鲈鱼、带鱼、鲭鱼、基围虾）。
猪牛羊红肉：每月只吃1-2次，解馋即可。
🥚 蛋奶豆怎么吃？ 鸡蛋：每天1个（水煮或蒸）。
奶制品：每天1杯纯牛奶或无糖酸奶（乳糖不耐受喝舒化奶或豆浆）。
🌰 零食吃什么？ 每天一小把原味坚果（核桃、花生、巴旦木，约20克）。
水果：每天2个拳头大小（推荐苹果、橙子、蓝莓）。
🧂 调料怎么放？ 少放盐和酱油，多用葱、姜、蒜、花椒、八角、桂皮来增香提鲜。
❌ 必须避开什么？ 甜饮料、果汁、含糖糕点——尽量戒掉；肥肉、动物内脏、猪油——尽量少吃。
📋 一日三餐万能模板 早餐：杂粮粥/全麦馒头 + 水煮蛋 + 凉拌黄瓜
午餐：清蒸鱼 / 香菇鸡胸 + 蒜蓉油麦菜 + 杂粮饭
晚餐：豆腐白菜汤 / 白灼虾 + 凉拌菠菜 + 蒸红薯
💡 中国胃关键心态 不用刻意吃冷沙拉！清炒、清蒸、水煮、炖汤都完全符合标准，只要做到油好、肉少、菜多、主食粗，就是最适合中国人的长寿饮食法。

体重

自重训练过程，你想进阶，自然就会意识到体重过大，会导致你无法完成动作，另外饮食结构的调整，吃的简单，少盐，少精粮后自然体重会下去，搭配运动，体重会持续缓慢往下，回到健康状态这是必然的结果。

坚持

千里之行始于足下，流水不争先后，争的是滔滔不绝；身体的衰老，肌肉的消失，关节的磨损，都是日积月累导致，而我们将采取行动，减缓这类衰老，保证我们能够灵活使用我们的身体，这是刻不容缓的事情，这是我们除了吃饭睡觉以外第三重要的事情，祝大家都能坚持下去，拥有健康的身体。

勿以善小而不为，勿以恶小而为之。共勉

## 摘要

2026年，中国经济呈现一幅极具张力的图景：住户存款余额突破173万亿元，社会消费品零售总额增速却在5月转负；规模以上工业增加值保持5.4%的增长，固定资产投资却同比下降5.7%。钱在增加，消费在收缩；供给在扩张，需求在萎缩。内需不足的根源不在消费意愿，而在分配机制；不在货币政策，而在体制激励。本文从数据出发，追溯制度根源，分析改革路径，并审视改革落地的现实约束。

## 一、现象：钱在增加，消费在收缩

2026年上半年，中国经济数据呈现出一种令人不安的背离。

| 指标 | 2026年上半年 | 含义 |
| :--- | :--- | :--- |
| 住户存款余额 | 173.48万亿元（6月末） | 上半年新增7.58万亿元 |
| 住户贷款 | 净减少3668亿元 | 有统计以来首次半年度净减少 |
| 社会消费品零售总额 | 同比+1.3% | 5月单月同比-0.6%，2023年以来首次转负 |
| 固定资产投资 | 同比-5.7% | 基建-2.4%，制造业-1.2%，房地产-18.0% |
| 规模以上工业增加值 | 同比+5.4% | 工业对经济增长贡献率超35% |

钱不是没有，而是越来越多停留在居民资产负债表里。供给在惯性扩张，需求在持续收缩。这种背离不是偶发的，而是一个自我强化循环的外在表现。

## 二、根源：四个结构性约束

### 2.1 收入分配：蛋糕切法决定消费能力

| 指标 | 中国 | 国际对比 |
| :--- | :--- | :--- |
| 劳动者报酬/GDP | 约53.22% | 全球平均约60% |
| 住户可支配收入/GDP | 67.80% | 与2002年持平，无实质改善 |
| 城乡居民收入比 | 2.4 | 农村财产性收入偏低 |
| 最富裕10%家庭财富占比 | 66.8% | 最贫困10%仅0.6% |

高收入群体边际消费倾向低，低收入群体想花没钱。**有钱的不想花，想花的没钱**——这是消费疲软最直接的微观基础。北大国发院报告指出，国企、垄断行业及重资本行业仍存在显著“劳动折价”——劳动者边际产出与实际工资之间存在系统性偏差。

### 2.2 社会保障：预防性储蓄的“锁定效应”

| 指标 | 中国 | 国际对比 |
| :--- | :--- | :--- |
| 社会保障支出/GDP | 11% | OECD平均约21% |
| 城乡居民养老保险月均 | 246元 | 农村人均收入的13% |
| 医疗自付比例 | 约35% | 远高于发达经济体 |
| 预防性储蓄率 | 32.4% | 远高于疫情前29.6% |

居民不是“不想花”，而是“不敢花”。世界银行测算：养老金翻倍可提升消费2%—4%，成本仅为GDP的0.6%。

### 2.3 财政支出结构：投资于物 vs 投资于人

| 支出类别 | 中国 | OECD平均 |
| :--- | :--- | :--- |
| 资本性支出 | 43% | 13.5% |
| 卫生、教育、社保合计 | 28% | 超过60% |

2026年四大民生领域支出合计12.4万亿元，占比41.3%，达近年最高点，较上年增长5.4%，高于全国一般公共预算支出增幅1个百分点。方向在改善，但绝对水平仍有显著差距。

### 2.4 全球价值链中的“劳动报酬陷阱”

| 指标 | 中国 | 德国 | 日本 |
| :--- | :--- | :--- | :--- |
| 出口产品附加值率 | 21.3% | 45.6% | 38.9% |
| 制造业劳动报酬占增加值（2000） | 48.7% | — | — |
| 制造业劳动报酬占增加值（2023） | 41.2% | — | — |

西南财经大学研究证实：外需扩张本身就在抑制劳动收入份额。出口企业获得更强市场势力后，收益未流向劳动者，而是在资本和销售环节被重新分配。

## 三、机制：自我强化的收缩循环

**劳动收入被压低 → 消费能力不足 → 企业面对疲弱内需 → 进一步压缩人力成本 → 劳动收入更低**

2026年微观案例清晰展示了这一循环：某车灯企业一年减员近2900人，劳务外包工时增长3倍多；某快递龙头将固定月薪15%划为季度绩效；星宇股份解除107名应届生劳动合同。企业行为并非道德问题，而是在需求收缩与竞争加剧双重压力下的系统性选择：**在终端产品被持续压价的背景下，人力成本成为最容易被压缩的变量。**

## 四、国际镜鉴：全球化背景下的普遍趋势

| 经济体 | 劳动者报酬/GDP | 统计口径 | 数据年份 |
| :--- | :--- | :--- | :--- |
| 中国 | 约52%—53% | 初次分配劳动报酬比重 | 2025 |
| 美国 | 53.8% | BLS劳动者报酬 | 2025Q3 |
| 欧盟 | 48.0% | Eurostat雇员报酬 | 2025 |
| 韩国 | 66.8% | 雇佣者报酬/国民收入 | 2025 |

> 口径说明：中国口径包含自雇者收入估算，美欧口径仅统计雇员报酬，跨国直接比较需谨慎。

美国劳动者报酬占GDP比重在2025年Q3降至53.8%，创1947年以来最低。劳动份额被压缩是全球性趋势。但中国的特殊性在于**双重挤压**：劳动份额偏低+社会保障薄弱。

## 五、政策信号：方向已定

| 政策文件 | 核心目标 | 具体措施 |
| :--- | :--- | :--- |
| 2026年政府工作报告 | 首次提出“城乡居民增收计划” | — |
| “十五五”规划纲要 | 提高劳动报酬在初次分配中的比重 | 健全最低工资标准调整机制 |
| 2026年集中要约行动 | 推行工资集体协商 | 力争百人以上企业集体合同率动态保持在85%以上 |
| 消费税改革 | 推进征收环节后移并稳步下划地方 | 增加地方自主财力，引导地方改善消费环境 |

方向明确：从制度层面为劳动者议价能力提供支撑，反向拉动企业分配向居民倾斜。但政策的效力，最终取决于执行力度与企业实际行为的博弈。**政策要求企业“多分”与市场逼迫企业“少分”之间的矛盾，将持续存在。**

## 六、改革路径：从生产型体制到分配型体制

| 改革领域 | 核心方向 | 关键举措 | 主要挑战 |
| :--- | :--- | :--- | :--- |
| 收入分配 | 提高劳动报酬占比 | 工资集体协商、技能导向薪酬 | 企业承受力与劳动者议价能力 |
| 社会保障 | 降低预防性储蓄 | 养老金上调、国资划转社保（已划转2.26万亿元） | 地方财政压力 |
| 财政支出 | 投资于人 | 公共服务支出占比提升 | 土地收入萎缩 |
| 要素市场化 | 纠正价格扭曲 | 10地试点，资本成本反映稀缺性 | 既得利益格局 |
| 财税体制 | 地方税体系建设 | 消费税下划地方 | 央地财政关系调整 |
| 户籍与公共服务 | 常住地提供服务 | 取消参保户籍限制 | 地方执行意愿 |

**核心判断：** 改革方向明确——从“生产型体制”转向“分配型体制”。但改革的实际速度，取决于三个变量：**财政空间的约束、企业行为的博弈、地方激励的转型速度。** 消费税下划地方等财税改革，有望从根本上改变地方政府“重生产、轻消费”的行为逻辑，但改革从试点到全面推广仍需时间。

## 七、改革能否成功：方向已定，落地存在时滞

### 7.1 顶层方向明确，基层门槛仍在

2026年5月，国务院印发《关于推行常住地提供基本公共服务的实施意见》，首次明确“逐步消除基本公共服务与户籍挂钩因素”，要求以居住证和居住年限互认为抓手，促进公共服务接续享有。国家发改委披露，长期在城镇居住生活但未落户的群众超过2.5亿人。

然而，政策文件与基层落地之间存在明显时滞。开封、石家庄、成都等地居住证申领仍要求“居住半年以上”或“社保满半年”。这些门槛并非新设，而是《居住证暂行条例》的既有规定。改革的方向是**让这张凭证更容易获得，而非取消凭证本身**。

### 7.2 三重约束

| 约束 | 核心问题 | 当前状态 |
| :--- | :--- | :--- |
| 制度惯性 | 居住证仍将是公共服务获取的“入口” | 政策方向是“更好发挥凭证功能” |
| 财政约束 | “钱随人走”机制能否覆盖服务成本缺口 | 从试点走向铺开，分配规则仍在调整 |
| 地方执行意愿 | 基本公共服务能否成为刚性考核指标 | 已纳入高质量发展综合绩效评价 |

### 7.3 核心判断

居住门槛反映的不是改革方向的倒退，而是**制度转换的成本**——旧制度尚未完全退出，新制度尚未完全到位。新生代农民工占比已超50%，举家迁移比例超过60%，流动人口对流入地的诉求已从“一张床位+一份工作”升级为涵盖子女教育、老人康养的全周期公共服务。**居民对改革的期待是具体的、即时的，而改革的落地是渐进的、结构性的。两者的时间差，就是居民感受中的“落差”。**

改革能否成功，最终取决于两个标志性变化：**居住证从“需要满足条件才能拿到”变成“登记即享有”，以及社保、教育、医疗等核心公共服务在常住地“无差别可及”。**

## 结论

内需不足的根源可以归结为一句话：**这套体制在激励“生产”方面极其高效，在激励“分配”方面却严重失衡。**

| 维度 | 生产型体制特征 | 分配型体制方向 |
| :--- | :--- | :--- |
| 公共资源配置 | 投资优先，基建占预算43% | 民生优先 |
| 要素市场化 | 资本便宜劳动昂贵 | 让资本成本反映真实稀缺性 |
| 收入分配 | 劳动报酬占比53%，劳动折价显著 | 提高劳动报酬在初次分配中的比重 |
| 社会保障 | 社保支出占GDP仅11% | 从“保基本”转向“促消费” |
| 地方激励 | GDP考核驱动投资冲动 | 转向服务居民和民生改善 |
| 户籍与公共服务 | 户籍绑定，梯度供给 | 常住地提供，无差别可及 |

供强需弱的闭环，不是一天形成的，也不会因一项政策而瓦解。它需要一场从“生产型体制”向“分配型体制”的深层转型。这场转型的成败，最终将决定中国经济的下一个十年。

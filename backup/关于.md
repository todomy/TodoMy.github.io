## 这里写什么

| 方向 | 主要内容 |
| :--- | :--- |
| **认知** | 读了什么、想了什么，以及一些不愿随大流的判断 |
| **投资** | 市场与人性的观察，记录判断，也记录错误 |
| **日常** | 生活里值得记一笔的碎片 |

## 为什么写

写作是把模糊的念头逼成清晰句子的过程。这里不急着给结论，只保留推演的过程，包括那些后来被自己推翻的部分。如果某篇文章能让你在合上页面后多想三分钟，那它就值了。

## 声明

本站内容多为个人视角的整理与推演，不构成任何投资建议或行动指南。正如每篇末尾那句：以上内容纯属虚构，瞎写写勿传播。
